# Iterkeep

Iterkeep, Windows için local-first bir çalışma ve bilgi yönetimi masaüstü uygulamasıdır. Ürün henüz geliştirme aşamasındadır; yayınlanmış bir sürüm yoktur.

## Geliştirme

Gereksinimler:

- Node.js 24 LTS
- npm 10 veya 11
- Windows 11 x64 (paketleme doğrulaması için)

```powershell
npm ci
npm run verify
npm run dev
```

Mimari ve ürün sözleşmeleri [docs/00-README.md](docs/00-README.md) dosyasından, uygulama sırası ise [docs/35-IMPLEMENTATION-PLAYBOOK.md](docs/35-IMPLEMENTATION-PLAYBOOK.md) dosyasından başlar. Katkı yapan kodlama ajanları önce [AGENTS.md](AGENTS.md) talimatlarını okumalıdır.
